"This is a clean and concise JavaScript function that checks whether a given number is **even** or **odd** using the modulo operator (`%`) and a ternary operator (`? :`).\n\n### How it works:\n1. `num % 2` divides the number by 2 and returns the remainder.\n2. If the remainder is `0` (meaning the number is perfectly divisible by 2), it returns `\"Even\"`.\n3. Otherwise, it returns `\"Odd\"`.\n\n### Examples of usage:\n```javascript\nconsole.log(checkNumber(4));   // Output: \"Even\"\nconsole.log(checkNumber(7));   // Output: \"Odd\"\nconsole.log(checkNumber(0));   // Output: \"Even\"\nconsole.log(checkNumber(-3));  // Output: \"Odd\"\n```\n\n### ⚠️ Edge Cases to Consider:\n\n1. **Non-integers (Decimals):**\n   If you pass a decimal like `1.5`, it will return `\"Odd\"` because `1.5 % 2` is `1.5` (not `0`). Technically, even/odd classification only applies to integers.\n   \n2. **Non-numeric inputs:**\n   If you pass a string or `null`, JavaScript's type coercion might lead to unexpected results:\n   ```javascript\n   checkNumber(\"hello\"); // Output: \"Odd\" (because NaN % 2 is not 0)\n   checkNumber(null);    // Output: \"Even\" (because null is coerced to 0)\n   ```\n\n### Robust Version (Optional):\nIf you want to ensure the input is actually a valid integer before checking, you can write it like this:\n\n```javascript\nfunction checkNumber(num) {\n  if (!Number.isInteger(num)) {\n    return \"Please provide a valid integer\";\n  }\n  return num % 2 === 0 ? \"Even\" : \"Odd\";\n}\n```"
